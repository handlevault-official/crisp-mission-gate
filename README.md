# Crisp Mission Gate 🕵️‍♂️🔥

> An interactive, high-end tactical briefing and top-secret classified dossier portal designed to deliver secure, immersive, and classified micro-interactions.

Part of the **Crisp Suite** ecosystem—built for modern, aesthetic, and memorable web apps.

---

## 🌟 Key Features

* **Classified Dossier Envelope:** Features a cyberpunk tactical theme with a "TOP SECRET" stamp and smooth decryption/folding animations.
* **Tactical Screening Gate:** Guides users through a multi-stage security clearance process (Agent Alias, Password, Security Tier Level, Operation Target).
* **Light & Dark Mode Support:** Seamlessly toggles between a deep Obsidian tactical theme and a clean light mode via a floating header button.
* **Operational Briefing Pass:** Generates a secure clearance ticket with custom codes and mission action buttons (*"Accept Mission 🎯"* or *"Abort ⚠️"*).
* **Zero Backend / 100% Static:** Built using pure HTML, CSS, and Vanilla JavaScript. Fast, lightweight, and ready for instant deployment on **GitHub Pages**.

---

## 🚀 Tech Stack

* **Markup & Structure:** HTML5
* **Styling:** CSS3 (Custom Variables, Flexbox, Keyframe Animations, Share Tech Mono typography)
* **Logic:** Vanilla JavaScript (DOM manipulation, step-state handlers)
* **Hosting:** GitHub Pages
